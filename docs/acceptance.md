## 自动化验收

| 项目 | 设置 / 故障 | 通过标准 |
| --- | --- | --- |
| 链接约束 | BV、普通页面、p 参数、非法主机和非法 P | 规范化正确；仅接受支持的页面；不把任意链接交给下载器 |
| 分 P 隔离 | 同一 BV 的 P1/P2、不同 CID | 分 P、格式、临时文件及输出互不混用 |
| 格式选择 | 混合编码、同档多帧率、目标档位缺失 | 选择规则确定；兼容编码优先；缺失目标不会静默降级 |
| 权限与试看 | DRM、不可访问格式、时长不足 | 不绕权限；不把预览或残缺内容当作完整成品 |
| 持久化 | 保存任务、重启、非法记录 | 可读取合法任务；中断状态转为等待恢复；损坏记录给出错误 |
| 基本下载 | 完整 200、合法 206、未知长度 | 内容与预期一致；未知大小不伪造精确百分比 |
| Range 续传 | 中断后同一资源、可靠校验信息 | 从合法字节位置继续，最终字节及内容一致 |
| 服务器忽略 Range | 带 Range 请求返回 200 | 不把完整响应追加到旧文件 |
| 范围错误 | 206 起点错误、总长度变化、非法 Content-Range | 不继续写入不一致的字节 |
| 已下载与 416 | 文件恰好完成、文件过长、资源变化 | 区分完整与异常；无法确认时安全重下 |
| 地址刷新 | 403/404/410、新 URL、格式或资源变化 | 有限刷新；一致性不明时不拼接旧数据 |
| 校验信息不足 | 无强校验信息、弱 ETag | 不承诺安全原位续传，采取安全重新下载 |
| 重试边界 | 超时、500、429、Retry-After | 共享预算限制总重试；尊重等待；暂停可以打断等待 |
| 暂停取消 | 下载、校验、合并中触发 | 能停止当前操作，保留可复用文件，状态与操作一致 |
| 已完成流复用 | 视频或音频已完成，另一条失败 | 检查有效后复用；被修改或损坏则不复用 |
| 文件管理 | 中文、非法字符、保留名、长标题、重名 | 路径可用，不覆盖已有成品，任务拥有独立临时目录 |
| 单 P 闭环 | 本地分别生成视频与音频 | 封装成含两路流的 MP4，无重新编码 |
| 合并失败 | FFmpeg 非零退出、进程中断、临时文件残留 | 不标记完成，保留输入，可重新合并 |
| 媒体验证 | 缺音频、错分辨率、时长异常 | 拒绝提交错误文件；存在两路流不代替解码验收 |
| 成品提交 | 重名、提交前中断、提交后数据库未更新 | 不覆盖；重启可核对真实文件并恢复正确状态 |
| 队列容错 | 成功、失败、暂停任务混合 | 失败 P 不影响其他任务；不会重复并发执行同一任务 |
| 日志脱敏 | 签名 URL、Cookie、授权字段 | 导出日志不包含播放地址参数或授权内容 |
| 界面启动 | Qt offscreen --smoke-test | 构建界面并在限时内退出，不自动下载视频 |

测试未实际覆盖的行必须单独标为待验收，不能因 CI 总体变绿就默认全部通过。

续传边界：强 ETag、总长度和 CID/格式身份用于判断是否可以继续写入；ETag 不是远端内容的加密真实性证明。已完成流的本地 SHA256 用于缓存完整性检查，未完成 .part 暂无独立前缀校验。

## 人工验收

| 环境 / 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| Windows 10 x64 | 无 Python/FFmpeg 环境解压完整包 | 可启动、识别内置工具，无需安装运行依赖 |
| Windows 11 x64 | 同上 | 同上，中文路径和目录选择正常 |
| 真实普通视频 | 使用用户有权访问的单 P 视频 | 实际格式可选择；成品有声音，开头/中间/结尾正常 |
| 已知多 P 样本 | 内容仍可匿名访问时验证 BV12jup6AEVi 的 P1/P2 | 两个独立 MP4，标题、CID、时长和内容对应 |
| 实际暂停恢复 | 下载中暂停、关闭软件、再次启动并继续 | 不自动恢复下载；主动继续后安全完成 |
| 合并中退出 | 合并时关闭，重新启动后继续或重试 | 可复用输入，重新合并，不展示假完成文件 |
| 编码兼容 | H.264/AAC 与其他可封装格式 | 格式展示准确；所选播放器可播放目标编码 |
| 播放与同步 | 抽查开头、中间、结尾，必要时完整解码 | 声音存在，音画同步，无明显损坏 |
| 文件故障 | 不可写目录、空间不足、输出被占用 | 说明可操作原因，保留可恢复数据 |
| 可用清晰度变化 | 解析后格式消失、权限变化 | 失败说明明确，不降级或下载其他 P |
| 软件更新 | 替换应用目录，保留用户数据 | 任务记录仍可读取，不误覆盖已有成品 |
| 日志导出 | 导出后人工检查 | 无授权字段和签名播放地址；公开前仍需检查本地路径 |
